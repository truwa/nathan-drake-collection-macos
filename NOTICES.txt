Uncharted for Mac
=================

This app runs the Uncharted Windows port under Wine. It is not a native Mac
port. The game itself is not included. You choose the folder that contains
your own decrypted dump (eboot.bin, big2-ps4_Shipping.elf, big3-ps4_Shipping.elf).

Wine 11.18
  LGPL-2.1-or-later
  https://gitlab.winehq.org/wine/wine/-/releases/wine-11.18
  macOS x86-64 build: https://github.com/Gcenx/macOS_Wine_builds/releases/tag/11.18

KosmicKrisp
  MIT, part of Mesa 26.3.0-devel (git-063dfaeec5)
  https://docs.mesa3d.org/drivers/kosmickrisp.html
  This is the x86-64 build of the Vulkan SDK 1.4.363.0 driver. Wine runs as
  x86-64, so the arm64 build of that SDK cannot be loaded.

Uncharted Windows port
  GPL-2.0
  https://github.com/Supermedo/uncharted_pc
  The port's LICENSE file and the notices in licenses/ are included.
  NVIDIA DLSS is not included.
  Mac changes to the port runtime are applied at launch from source in this
  project (patch_probe.py and tls_adapter.c).
